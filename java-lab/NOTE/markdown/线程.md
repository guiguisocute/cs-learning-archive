### 实现
Java的多线程支持主要是基于JVM的设计，一个java程序实际上是一个JVM进程，JVM进程用一个主线程来执行`main`方法，但是我们可以在这个主线程中创建其他线程来并发执行任务。Java通过`java.lang.Thread`类和`java.lang.Runnable`接口来实现多线程编程。此外，gc也是在一个单独的线程中运行的。

### 创建新线程的方法
#### 直接继承
```java
class app {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();
        t1.start(); // 启动线程，调用run方法
    }
}
class MyThread extends Thread {
    public void run() {
        System.out.println("MyThread is running");
    }
}
```
具体不多解释，这是最基础的创建方式，通过.start()方法启动线程，JVM会调用run()方法。
#### 实现Runnable接口
```java
class app {
    public static void main(String[] args) {
        Thread t1 = new Thread(new MyRunnable());
        t1.start(); // 启动线程，调用run方法
    }
}
class MyRunnable implements Runnable {
    public void run() {
        System.out.println("MyRunnable is running");
    }
}
```
当然，因为runnable是一个函数式接口，我们也可以使用lambda表达式来简化代码：
```java
class app {
    public static void main(String[] args) {
        Thread t1 = new Thread(() -> {
            System.out.println("MyRunnable is running");
        });
        t1.start(); // 启动线程，调用run方法
    }
}
``` 

还可以这样：
```java
class Mythread extends Thread {
    thread t1 = new Thread(() -> {
        System.out.println("MyRunnable is running");
    });

}
```
