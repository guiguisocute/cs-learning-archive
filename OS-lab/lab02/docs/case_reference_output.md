# FCFS 样例参考输出

这个文档给出当前脚手架中每个 `data/*.txt` 的参考输出，便于你直接在终端运行后手动核对。

## 批量运行接口

单个样例：

```bash
./scripts/run_fcfs.exp data/case_fcfs_5.txt ./scheduler_lab
```

批量运行全部样例：

```bash
./scripts/run_fcfs.exp --all ./scheduler_lab data
```

如果省略后两个参数，默认就是当前目录下的 `./scheduler_lab` 和 `data/`。
